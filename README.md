## Stack
- **Backend:** Python (FastAPI, SQLite)
- **Frontend:** JavaScript, Tailwind CSS (CDN)
- **Testing:** Pytest, Robot Framework, Postman

## How to Run
1. **Backend:** `cd app/backend`, activate `venv`, run `uvicorn main:app --reload`
2. **Frontend:** `cd app/frontend`, run `npx serve .`
3. **Tests:** `pytest ../../tests/unit/test_api.py` and `python -m robot ../../tests/robot/`
